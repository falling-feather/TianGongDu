### 4.1 玩家现在实际能完成的稳定路线

稳定 Web Host 加载唯一 1.4 包后，玩家可在灰盒江南场地移动并受到双门碰撞限制；进入伞作工位后可购买高成本柔性补片或低成本硬质补片，按“对齐伞骨 → 贴补 → 雨试”的顺序操作。高成本路线以品质 `9000` 直接通过；低成本路线首次雨试失败后可“重新张紧”并复试，品质从 `6500` 提升到 `8400`。随后玩家以 `Y` 交付订单，获得一次性资金奖励并通过 authored interaction → mechanism → blocker 链打开右侧屋顶捷径，左侧主门仍保持关闭。

玩家继续操作主门后触发两波共四名敌人；稳定线使用“漏雨伞偶/pressure”和“牵索水役/flanker”两种机器身份，玩家以最小轻/重击完成两波、两个目标和 terminal。敌方可以自然击倒玩家；`R` 会在当前单 Host 内重建 Workshop/Craft、两条 blocker、Encounter/Combat、目标和作者 safe point。重复交付、重复机关和错误工序均保持幂等或零漂移。

Workbench 当前可修改六类场地对象的创建、复制、受控删除、位置、朝向、区域、范围和资源引用；可修改已有 Actor profile/faction/duty/health、Wave/Objective、Craft material/workstation/process/step、Workshop stock 和 Order 字段。保存后可 Launch 当前 fresh package，Safe Reload 在候选 Host 真正 C++ 启动并返回匹配 token/generation 前保留旧画面；编译失败、stale lease、请求错误或超时都不替换 last-valid。
